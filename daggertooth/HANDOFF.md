# 📋 프로젝트 인수인계 문서 (HANDOFF)

## 1. 프로젝트 개요
- **프로젝트명**: 팀 소개 및 동적 프로젝트 포트폴리오 웹사이트
- **현재 브랜치**: `daggertooth`
- **목적**: 기존 레이아웃 및 인터랙티브 기능(팀원 프로필 수정 모달, 동적 새 프로젝트 등록/삭제 등)을 그대로 유지하면서, 지정된 컬러 팔레트(Light/Dark Mode)를 CSS 변수로 정밀 적용한 웹사이트

### 2.2 적용된 테마 컬러 팔레트 (CSS 변수)

1. **Light Mode Palette**:
   - `#F9E8A2` (버터 옐로우: 테마 토글 호버 등 하이라이트)
   - `#B4E1EB` (소프트 스카이 시안: 역할 배지 및 태그 보더)
   - `#95BDD7` (슬레이트 블루: 토글/입력창 테두리, 그라디언트 보조)
   - `#78A4CB` (프라이머리 블루: 호버 하이라이트, 메인 액션 버튼)
   - 텍스트/서피스: 소프트 라이트 배경(`#f4f8fb`), 딥 슬레이트 텍스트(`#183144`)

2. **Dark Mode Palette**:
   - `#213C51` (딥 네이비: 카드 배경 서피스 및 모달 배경)
   - `#6594B1` (슬레이트 블루: 토글 보더, 태그 호버, 저장 버튼 그라디언트)
   - `#DDAED3` (라일락 핑크: 카드 호버 외곽선, 역할 뱃지 강조, 입력창 포커스 링)
   - `#EEEEEE` (화이트 라이트: 주요 텍스트 및 태그 폰트 컬러)
   - 텍스트/서피스: 딥 백그라운드(`#152736`), 선명한 라이트 텍스트(`#EEEEEE`)

### 2.3 보존된 주요 기능
1. **팀원 프로필 수정 모달**: 팀원 카드 클릭 시 모달 오픈, 이름/역할/소개/아바타 실시간 미리보기 및 `🎲 랜덤` 아바타 생성, `localStorage` 저장
2. **동적 프로젝트 등록 및 관리**: '새 프로젝트 등록하기 (+ 카드)' 클릭 시 모달 오픈, 동적 카드 생성, 개별 삭제, 빈 상태 안내 문구 노출 및 `localStorage` 보존
3. **테마 전환**: 우측 상단 `☀️/🌙` 버튼을 통한 실시간 테마 토글
